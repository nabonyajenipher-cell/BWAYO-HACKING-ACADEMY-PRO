# BWAYO HACKING ACADEMY PRO

A responsive starter website for an ethical cybersecurity learning academy.

## Current starter features
- Homepage and course overview
- Six introductory lessons: cybersecurity foundations, networking, Linux, web security, account safety, and authorized testing
- One interactive knowledge-check question
- Student sign-in preview (demo only)
- Membership pricing display: UGX 1,000 per month

## Important launch requirements
This repository currently contains a front-end demonstration, not a production membership system.
- Do not collect real passwords through the demo form.
- Add a secure backend for registration, login, sessions, and role-based admin access.
- Integrate a supported MTN Mobile Money merchant/payment provider on the server.
- Verify payment callbacks server-side before granting or renewing monthly access.
- Keep API keys, merchant credentials, and secrets in server-side environment variables, never in browser JavaScript or this public repository.
- Add privacy, terms, refund, and support information before accepting students.

## Safety
All learning and practice must be limited to systems the learner owns or has explicit authorization to test. Use intentionally vulnerable labs for exercises.

## Run locally
Open `index.html` in a browser, or enable GitHub Pages in the repository settings to publish the static preview.
